## 思路

这道题是 LeetCode 141 的升级版：不仅判断有没有环，还要找到**环的入口节点**。解法分两个阶段：

1. **第一阶段**：用快慢指针判断有环，并让两指针在环内相遇（同 141）
2. **第二阶段**：把其中一个指针放回链表头，两个指针**同速（每次 1 步）**走，再次相遇的位置就是环的入口

### 核心公式推导

设：

- 链表头 → 环入口 的距离为 `a`
- 环入口 → 相遇点 的距离为 `b`
- 相遇点 → 环入口（环的剩余部分）为 `c`
- 环长 = `b + c`

**第一阶段**（快指针走 2 步，慢指针走 1 步）：

慢指针从 head 走到相遇点，走了 `a + b` 步。

快指针走了 `2 × (a + b)` 步。快指针比慢指针多走的部分，一定是在环里多绕的整圈：

```
2 × (a + b) = a + b + n × (b + c)
```

化简：

```
a + b = n × (b + c)
a = n × (b + c) - b
a = (n - 1) × (b + c) + c
```

**关键结论**：

```
a = (n-1) × 环长 + c
```

意思是：**从 head 走到环入口的距离 a，等于"从相遇点走 c 步到入口，再多绕 (n-1) 整圈"**。

### 第二阶段为什么相遇点就是入口

把慢指针放回 head，快指针留在相遇点。两个指针**同速走（每次 1 步）**：

- head 指针走 `a` 步 → 正好到达环入口
- 相遇点指针走 `a` 步 → 走了 `c + (n-1) × 环长` → 也就是"先走 c 步到入口，再绕了 (n-1) 整圈回到入口"

**两个指针走了相同的步数后，同时落在环入口。** 相遇点 = 环入口。

### 为什么慢指针第一次进环后，一圈之内必被追上

慢指针刚进环时，快指针在环内某个位置，两者距离最多是"环长 - 1"。快指针相对慢指针每轮追近 1 步，所以最多追"环长 - 1"轮就追上——慢指针还没来得及走完一整圈就被追上了。这就是为什么慢指针第一阶段只走了 `a + b`，不用额外加圈数，公式才能简化。

### 生活化比喻

两个人从操场外的马路上出发，进了环形跑道绕圈。跑步的人（fast）先进了操场，在跑道某处等。走路的人（slow）进操场后，两人在跑道上某点相遇。

现在把走路的人拉回马路的起点，两人**都用同样的速度走**。走路的人再次走到操场门口时，操场里那个人也正好绕回操场门口——因为"门口到相遇点"和"相遇点绕回门口"的距离关系刚刚好。门口就是环的入口。

## 解题过程

**第一阶段**：

1. `slow = head`, `fast = head`
2. `while fast and fast.next:` → `slow` 走 1 步，`fast` 走 2 步
3. 相遇（`slow == fast`）→ 有环，进入第二阶段
4. 没相遇（fast 到 None）→ 无环，返回 None

**第二阶段**：

1. `slow = head`（放回链表头），fast 留在相遇点
2. `while slow != fast:` → 两指针**都走 1 步**
3. 再次相遇 → 这个节点就是环入口，返回它

**关键点**：第二阶段两个指针必须**同速**（都是每次 1 步）。如果还保持一快一慢，它们相遇的位置就不一定是入口。

---

## 复杂度

- 时间复杂度: **O(n)** —— 第一阶段慢指针走 a + b，第二阶段 head 指针走 a，总路程不超过 2n
- 空间复杂度: **O(1)** —— 只使用两个指针

## 易错点

1. 无环的情况忘记返回 None。

   fast 走到末尾说明无环，题目要求返回 None，不是返回 False。

2. 第二阶段忘了把 slow 放回 head。

   直接在第一阶段的相遇点继续走是找不到入口的——必须一个指针回到 head，且两个指针同速。

3. 第二阶段两指针速度不一致。

   正确：都走 1 步。如果 fast 还走 2 步，再次相遇的点不是环入口。

4. 公式记混。

   记核心结论：`a = (n-1) × 环长 + c`——head 到入口的距离，等于相遇点到入口的距离加上若干整圈。

## 示例

```text
链表: 3 → 2 → 0 → -4
           ↑__________↓
环入口是节点 2

head 到入口: a = 1（3 → 2）

第一阶段:
  初始: slow=3, fast=3
  第1轮: slow=2, fast=0
  第2轮: slow=0, fast=2
  第3轮: slow=-4, fast=-4 → 相遇于 -4

第二阶段:
  slow 放回 head=3，fast 留在 -4
  第1轮: slow=2, fast=2 → 相遇！

返回节点 2 ✅（环入口）
```

验证公式：a = 1，环长 = 3（2 → 0 → -4 → 2），相遇点 -4 到入口 2 的 c = 1。1 = 0 × 3 + 1 ✅
