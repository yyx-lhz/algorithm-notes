# Day 26 · LeetCode 56：合并区间

## 我的思路：先排开头，再比较“屁股”

先按每个区间的第一个元素，也就是左端点，从小到大排序。然后依次看每个新区间：拿它的开头，和结果中最后一个区间的“屁股”（右端点）比较。

- 如果结果还是空的，先把当前区间放进去。
- 如果 `start <= last_end`，说明两个区间重叠或端点相接，可以合并。比较两个“屁股”，把伸得更远的那个留下，也就是更新为 `max(last_end, end)`。
- 如果 `start > last_end`，说明两个区间之间有空隙，直接把新区间加入结果。

这里“屁股更长”指的是**右端点更大**，不是比较区间长度。判断能不能合并时要用 **小于等于**：例如 `[1, 4]` 和 `[4, 5]` 在 4 处相接，也要合成 `[1, 5]`。

## 为什么先排序，只和最后一个区间比较？

按左端点排序后，新区间的开头不会比之前处理过的开头更小，因此合并时左端点不用变，只需要考虑右端点能不能往右延伸。

结果中的区间始终按顺序排列、互不重叠。新区间如果能接上已处理的部分，只可能接上最后一个区间；如果连最后一个区间都接不上，更前面的区间也接不上，所以不用回头逐个比较。

注意比较的是**结果中最后一个已经合并好的区间**，不是原数组里紧挨着的上一个区间。例如 `[[1, 10], [2, 3], [4, 5]]` 最终应合为 `[[1, 10]]`。

## 跟着例子走一遍

输入：`[[8, 10], [1, 3], [15, 18], [2, 6]]`。

先排序：`[[1, 3], [2, 6], [8, 10], [15, 18]]`。

| 当前区间 | 判断与操作 | result |
|---|---|---|
| `[1, 3]` | 结果为空，直接加入 | `[[1, 3]]` |
| `[2, 6]` | `2 <= 3`，右端点更新为 `max(3, 6) = 6` | `[[1, 6]]` |
| `[8, 10]` | `8 > 6`，直接加入 | `[[1, 6], [8, 10]]` |
| `[15, 18]` | `15 > 10`，直接加入 | `[[1, 6], [8, 10], [15, 18]]` |

## Python 3 代码

完整代码：[56-merge-intervals.py](./56-merge-intervals.py)。

```python
from typing import List


class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort(key=lambda x: x[0])
        result = []

        for start, end in intervals:
            if not result or start > result[-1][1]:
                result.append([start, end])
            else:
                result[-1][1] = max(result[-1][1], end)

        return result
```

代码先处理“结果为空或不能合并”的情况，剩下的 `else` 就是 `start <= result[-1][1]`，执行合并。

## 两处语法的理解

### `intervals.sort(key=lambda x: x[0])`

`sort` 会直接修改原列表的顺序；`lambda x: x[0]` 表示“拿到一个区间 x，返回它的第一个元素作为排序依据”。

### `result[-1][1]` 和 `result[-1][-1]`

先用 `result[-1]` 取最后一个区间，再用 `[1]` 取这个区间的第二个元素，也就是右端点。

例如 `result = [[1, 6], [8, 10]]`，则 `result[-1]` 是 `[8, 10]`，`result[-1][1]` 是 `10`。每个区间只有 `[start, end]` 两个元素，所以这里 `result[-1][-1]` 也等于 `10`；写 `[1]` 更明确地表示取 end。

## 易错点与复杂度

- **端点相等也合并**：`[[1, 4], [4, 5]]` 得到 `[[1, 5]]`。
- **右端点必须取 max**：`[[1, 10], [2, 3]]` 仍然是 `[[1, 10]]`，不能直接把右端点改成 3。
- **先判断结果是否为空**：空列表不能读取 `result[-1]`。代码中的 `or` 会短路，结果为空时不会访问右侧。
- **时间复杂度 O(n log n)**：排序 O(n log n)，遍历 O(n)。
- **空间复杂度 O(n)**：结果最多保存 n 个区间；Python 排序最坏也需要 O(n) 辅助空间。

> 复习口诀：先排开头，再看屁股；开头不超过屁股，留下更远的屁股；有空隙就另起一段。
