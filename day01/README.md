# Day 01 · 2026-05-28

**题目**: [LeetCode 15. 三数之和](https://leetcode.cn/problems/3sum/)

**标签**: 数组 / 双指针 / 排序 / Python3

---

## 思路

**你选用何种方法解题?**

三个数字肯定要"动中取静"才可以 —— 先把第一个数确定下来,然后让剩下两个数的和变成第一个数的负数,就可以用双指针了。

那双指针怎么用?首先排个序,这样问题就变成了"两数和为 target":

- 从左右两个指针开始
- 数大了,右指针左移
- 数小了,左指针右移
- 然后要记得**有重复的不行**,所以要检查 `+1` 或者 `-1` 的数,如果相等就继续 `+1` 或者 `-1`

---

## 解题过程

1. 首先需要三个指标 (`i`, `k`, `j`),而且 `k` 和 `j` 是根据 `i` 动的,所以**先排序固定 i**。
2. 可能有多个满足条件的三元组,所以要有一个空数组 `res`。
3. `k = i + 1`, `j = len(nums) - 1`,然后用 `sum = nums[k] + nums[j]` 来计算和 `0` 的差距(实际比较 `sum + nums[i]`):
   - 如果大于 0,右指针左移 (`j -= 1`)
   - 如果小于 0,左指针右移 (`k += 1`)
   - 如果等于 0,加入 `res`
4. 但要考虑**重复的情况**,所以在三元组成立后,要跳过和 `nums[k]`、`nums[j]` 相同的相邻元素 —— 检查 `k+1` 和 `j-1`。

---

## 错误问题(踩坑)

1. **首先就要用空数组来包含** —— 结果不止一个三元组。
2. **数组重复问题,应该看最先发生问题的** —— `nums[i] == nums[i-1]` 时直接 `continue`,而不是处理完再判断。
3. **`i - 1` 要确认 `i > 0`** —— 否则越界。
4. **重复要有正确的顺序,右边的是减** —— 内层 `while` 跳重复时,`k` 是 `+=`、`j` 是 `-=`,方向不能搞混。
5. **双指针要记得排序** —— 没排序双指针思路根本不成立。

---

## 复杂度

- 时间复杂度: **O(n²)** —— 外层 `O(n)` 循环 i,内层双指针 `O(n)`
- 空间复杂度: **O(log n)** —— 排序使用的栈空间(不计入结果数组)
