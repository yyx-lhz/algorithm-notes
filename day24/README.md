# Day 24 · LeetCode 215. 数组中的第 K 个最大元素

**题目**: [LeetCode 215. 数组中的第 K 个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

**标签**: 数组 / 堆 / 小顶堆 / heapq / Python3

---

## 我的思路：留住最大的 k 个数

我想找第 k 大，可以先想：把最大的 k 个数留下来，里面最小的那个不就是第 k 大吗？

所以不用“先找最大，再找第二大”这样一个个找。准备一个小顶堆，每来一个数就先塞进去；如果里面超过 k 个，就把当前最小的那个踢掉。这样每轮处理完，留下的就是目前见过的最大的 k 个数。还没见够 k 个时，就先全部留下。

最后看堆顶，它就是这 k 个数里最小的那个，也就是整个数组的第 k 大。

这里的“第 k 大”按元素个数算，**不去重**。比如 `[6, 6, 5]` 的第 2 大还是 `6`。题目保证 `1 <= k <= len(nums)`，所以最后的堆不会为空。

## Heap 到底是什么？树还是列表？

Heap 就是“堆”。这里学的是二叉堆，概念上是一棵**完全二叉树**：除了最后一层，上面的层都填满；最后一层从左往右连续摆，不能中间空一块。

但在 Python 里，不一定要真的创建一个个树节点。通常直接用普通 `list`，按照树从上到下、从左到右的顺序存：

```text
        1
       / \
      4   2
     / \
    7   5

对应 list：[1, 4, 2, 7, 5]
```

对于下标 `i`，左孩子在 `2*i + 1`，右孩子在 `2*i + 2`；非根节点的父节点在 `(i - 1) // 2`。只要相应下标没有超出列表范围，就能在列表里找到它们。

### 小顶堆不是 BST，也不是完整排序

小顶堆只要求：**每个父节点 <= 它的子节点**。沿着这个关系往上看，根节点肯定是整个堆最小的数。

它不要求“左边一定小、右边一定大”，左右孩子之间也没有固定大小顺序。上面左孩子是 `4`，右孩子是 `2`，照样是合法小顶堆。

不要和二叉搜索树（BST）混淆：BST 对左右子树与根的大小关系有要求；小顶堆只维护父子之间的大小关系。`[1, 4, 2, 7, 5]` 没有完整排好序，但已经满足堆性质。除了 `heap[0]` 是最小值，不能把后面的下标直接当成第几小。

## 插入和删除时，堆怎么调整？

### 插入：先放最后，再上浮（sift up）

先把新元素放在完全二叉树的最后一个位置，也就是列表末尾，保证树的形状还是完全二叉树。

然后和父节点比较：如果新元素更小，就往上交换；继续与新的父节点比较，直到不需要交换，或者已经到了根节点。

比如 `[2, 5, 6]` 插入 `1`：

```text
先放末尾：[2, 5, 6, 1]
1 比父节点 5 小，交换：[2, 1, 6, 5]
1 比父节点 2 小，交换：[1, 2, 6, 5]
```

### 删除最小值：最后一个搬到堆顶，再下沉（sift down）

弹出的是根节点，也就是最小值。为了保持完全二叉树的形状，把最后一个元素搬到堆顶，同时删掉原来最后的那个位置。

再向下调整：和孩子中较小的那个比较，如果自己更大，就交换，继续往下走，直到恢复堆性质。如果只剩一个孩子，就和那个孩子比。原来只有一个元素时，弹出后直接变成空堆。

比如 `[1, 2, 6, 5]` 弹出 `1`：

```text
最后的 5 搬到堆顶：[5, 2, 6]
两个孩子中 2 更小，5 与 2 交换：[2, 5, 6]
```

这是理解堆操作的概念过程。用 `heapq` 时，这些调整由工具自动完成，不需要自己手写。

## “黑不 Q”其实是 heapq

`heapq` 是 Python 标准库里操作堆的模块。本篇使用的 `heappush`、`heappop` 默认维护**小顶堆**。

```python
import heapq  # 把 Python 的堆工具拿过来用
heap = []     # heap 本身就是普通 list
```

`heap` 是我们存数字的列表，`heapq` 是帮这个列表维护堆性质的工具。变量名叫 `heap` 不会自动让列表变成堆，要通过相应操作维护。

| 写法 | 大白话理解 |
|------|------------|
| `heapq.heappush(heap, num)` | 把 num 放进去，并自动调整成合法小顶堆 |
| `heapq.heappop(heap)` | 删除并返回当前最小值，并自动维护剩下的堆 |
| `heap[0]` | 只看当前最小值，不删除它 |

这里从空列表开始，一直用堆操作维护。不能随意往末尾 `append` 后就认为堆性质仍然成立。`heappop` 和 `heap[0]` 也都要求堆非空。

## “全塞进去，然后弹出 k 个”要怎么改？

所有数字都会经过一次 push，但**不是一次性把所有数字存进堆，再正好弹出 k 个**。这份代码是一边遍历、一边控制堆的大小：

```text
每来一个 num，先 push
          ↓
如果 len(heap) > k，就 pop 当前最小值
          ↓
每轮结束，最多保留 k 个，而且是目前最大的 k 个
          ↓
全部遍历结束，heap[0] 就是第 k 大
```

超过 k 个才弹，不是只要觉得这个数字“小”就直接弹。刚 push 后会短暂有 k+1 个，随后的 pop 把其中最小的踢掉。新来的数如果足够小，踢掉的可能就是它自己。

前 k 个数只入堆，不弹出；后面每来一个数，入堆后就弹一个。如果总共有 n 个数，最终一共弹出的是 **n-k 个**，不是固定 k 个。

## 为什么能保证最后堆顶就是第 k 大？

假设上一轮已经留下目前最大的 k 个数。新数来了以后，把它和这 k 个放一起，去掉最小的那个，剩下的仍然是目前最大的 k 个。

之前被踢掉的数，已经排不进当时的前 k 名；后续再加入新数，也不会让它重新挤进前 k 名，所以不需要找回来。重复值按出现次数保留，数值相同时踢掉哪一次都不影响答案。

遍历完以后，堆里保留的就是全数组最大的 k 个数。**小顶堆顶部是这 k 个数里最小的那个，所以它正好是全数组第 k 大。**

## 跟着例子走一遍

`nums = [3, 2, 1, 5, 6, 4]`，`k = 2`。我们只想留下最大的两个数：

| 当前 num | push 后的 heap | 是否超过 2 个、弹出谁 | 本轮结束的 heap |
|----------|----------------|----------------------|----------------|
| `3` | `[3]` | 没超过，不弹 | `[3]` |
| `2` | `[2, 3]` | 没超过，不弹 | `[2, 3]` |
| `1` | `[1, 3, 2]` | 超过，弹出最小值 `1` | `[2, 3]` |
| `5` | `[2, 3, 5]` | 超过，弹出最小值 `2` | `[3, 5]` |
| `6` | `[3, 5, 6]` | 超过，弹出最小值 `3` | `[5, 6]` |
| `4` | `[4, 6, 5]` | 超过，弹出最小值 `4` | `[5, 6]` |

最后留下 `5` 和 `6`，堆顶 `heap[0] = 5`，所以第 2 大是 `5`。一共 push 了 6 次，pop 了 4 次，正好是 `n-k = 6-2 = 4`，不是弹出 2 次。

注意表里的 `[1, 3, 2]`、`[4, 6, 5]` 并没有完整排序，但都是合法小顶堆。最后 `[5, 6]` 看起来有序，只是这个例子剩下两个数；算法需要的始终只是堆性质。

## Python 3 代码

完整代码：[215-kth-largest-element-in-an-array.py](./215-kth-largest-element-in-an-array.py)。

```python
import heapq

class Solution:
    def findKthLargest(self, nums: list[int], k: int) -> int:
        heap = []

        for num in nums:
            heapq.heappush(heap, num)

            if len(heap) > k:
                heapq.heappop(heap)

        return heap[0]
```

`if` 在 `for` 里面：每来一个数就检查大小。`return heap[0]` 在 `for` 外面：一定要看完全部数字再返回，不能处理一个数就提前结束。

| nums | k | 结果 | 说明 |
|------|---|------|------|
| `[3, 2, 1, 5, 6, 4]` | `2` | `5` | 最后保留 5 和 6 |
| `[3, 2, 3, 1, 2, 4, 5, 5, 6]` | `4` | `4` | 重复元素也占排名 |
| `[6, 6, 5]` | `2` | `6` | 不能先去重 |
| `[-3, -1, -2]` | `2` | `-2` | 负数也按同样规则处理 |
| `[7]` | `1` | `7` | 单元素 |
| `[3, 1, 2]` | `1` | `3` | k=1，就是找最大值 |
| `[3, 1, 2]` | `3` | `1` | k=n，没有 pop，第 n 大就是最小值 |

## 复杂度与题目要求

设 `n = len(nums)`。

- 时间复杂度：通常写作 **O(n log k)**。遍历 n 个数，每轮最多一次 push、一次 pop，堆的大小最多短暂达到 k+1，调整沿着树高进行。严格兼顾 `k=1` 时，可写 **O(n log(k+1))**；此时每轮是常数操作，总时间为 O(n)。
- 辅助空间复杂度：**O(k)**。每轮结束最多 k 个，push 后短暂 k+1 个也仍是 O(k)。

如果题目严格要求平均 **O(n)**，应使用 **Quickselect（快速选择）** 来满足这个目标，常见随机化版本平均 O(n)、最坏 O(n²)。本篇以堆解法为学习重点，不把 O(n log k) 说成平均 O(n)。
