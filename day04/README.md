# Day 04 · 2026-06-18

**题目**: [LeetCode 3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

**标签**: 字符串 / 滑动窗口 / 双指针 / 哈希表 / Python3

---

## 思路

**你选用何种方法解题?**

这道题的暴力解法就是遍历字母,然后找相邻的扔进中心的里面,如果次数 > 1 那就结束。但神奇做法就是去掉左边的,就一直去,直到不重复。

本质就是**滑动窗口**:用两个指针 `left` / `right` 维护一个"窗口",窗口里始终保证**无重复字符**。`right` 每次往右扩,如果新加进来的字符让窗口出现重复,就持续把 `left` 往右挪,直到重复消失,然后记录这一刻的窗口长度。

---

## 解题过程

1. 初始化 `ans = 0`、`cnt = Counter()`(记录窗口内每个字符出现次数)、`left = 0`。
2. `right` 从 0 遍历到 `len(s) - 1`,每次:
   - `cnt[c] += 1` 把新字符加进窗口。
   - 如果 `cnt[c] > 1`(说明新加的这个字符在窗口里已经存在了),进入收缩循环:
     - 每次 `cnt[s[left]] -= 1`,`left += 1`,把左边字符吐出窗口。
     - 直到 `cnt[c] == 1`,即重复消除。
   - 更新答案 `ans = max(ans, right - left + 1)`。
3. 返回 `ans`。

**关键点**:while 循环只在出现冲突的当前字符上判断 `cnt[c] > 1`,不需要遍历整个窗口检查重复 —— 因为窗口在加入 `c` 之前是无重复的,新冲突只可能来自 `c` 本身。

---

## 复杂度

- 时间复杂度: **O(n)** —— 左右指针各自最多走 n 步,总共 2n
- 空间复杂度: **O(∣Σ∣)** —— Counter 的大小由字符集决定,ASCII 视作 O(1)
