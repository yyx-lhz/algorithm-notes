# Day 17 · LeetCode 189. 轮转数组

## 我的思路

先把 k 对数组长度 n 取余，也就是 `k %= len(nums)`，去掉重复轮转的整圈。然后取最后 k 个元素，移到最前面，再把前面剩下的部分接到后面。最后通过 `nums[:]` 把新顺序写回原列表。

- `k %= len(nums)`：取余，不是取除法的商；例如长度为 3、k 为 5 时，只需要右移 2 位。
- `nums[-k:]`：当 k > 0 时，取最后 k 个元素。
- `nums[:-k]`：当 k > 0 时，取前面剩余的元素。
- `nums[:] = ...`：修改原列表的内容；`nums = ...` 只会让函数里的变量指向新列表，调用者的原列表不会改变。

## 例子

```text
nums = [1, 2, 3, 4, 5, 6, 7], k = 3
最后 3 个：[5, 6, 7]
前面剩余：[1, 2, 3, 4]
拼接结果：[5, 6, 7, 1, 2, 3, 4]
```

## Python 3 代码

完整代码：[189-rotate-array.py](./189-rotate-array.py)。

```python
from typing import List


class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        k %= len(nums)
        nums[:] = nums[-k:] + nums[:-k]
```

## 边界与复杂度

- k 取余后为 0 时，`-0` 就是 `0`，所以 `nums[-k:]` 是整个列表，`nums[:-k]` 是空列表，拼接后顺序不变。
- 本题数组非空，因此可以直接对 `len(nums)` 取余。
- 时间：O(n)，切片、拼接和写回都需要处理数组元素。
- 额外空间：O(n)，切片和拼接会创建临时列表。这里修改了原列表，但不是 O(1) 额外空间的解法。
