# Day 14 · 2026-08-17

**题目**: [LeetCode 104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

**标签**: 二叉树 / 递归 / DFS / Python3

---

## 思路

最大深度 = 从根节点到最远叶子节点的**最长路径上的节点数**。

### 递归定义

一棵树的深度：

```
深度 = 1（根自己） + max(左子树深度, 右子树深度)
```

空树深度为 0，叶子节点的深度为 1。自底向上：先算出左右子树的深度，取较大者加 1，就是当前树的深度。

### 为什么递归天然适合

树的深度是**递归定义**的——"树的深度"这个概念的答案由"子树深度"组成。不需要显式的栈或队列，递归调用栈自动帮我们走到每一片叶子再逐层返回。

### 生活化比喻

问一栋楼的楼层数，不用爬上去数——问"左边的楼梯间有几层、右边的楼梯间有几层，取多的那个加 1"。每个楼梯间又用同样的办法问下去，一直问到最底层（空，0 层）。

---

## 解题过程

1. `if not root: return 0` — 空节点深度为 0（递归终止条件）
2. `left_depth = maxDepth(root.left)` — 左子树深度
3. `right_depth = maxDepth(root.right)` — 右子树深度
4. `return max(left_depth, right_depth) + 1` — 取大者加 1

**关键点**：终止条件必须写——空节点返回 0，否则递归无限进行下去。

---

## 复杂度

- 时间复杂度: **O(n)** —— 每个节点访问一次
- 空间复杂度: **O(h)** —— 递归栈深度为树高，最坏 O(n)（链状树），平均 O(log n)

## 易错点

1. 忘了空节点终止条件。

   `maxDepth(None)` 会继续调用 `None.left` 报 AttributeError。

2. 叶子节点返回 1 还是 0 分不清。

   叶子节点：左右子树深度都是 0 → `max(0,0)+1 = 1` ✅。空节点才是 0。

3. 忘记 +1。

   只返回 `max(left, right)` 的话，所有叶子都返回 0——深度少算了一层。

## 示例

```text
       3
     /   \
    9    20
        /  \
       15   7

maxDepth(3):
  maxDepth(9) = 1（叶子）
  maxDepth(20):
    maxDepth(15) = 1
    maxDepth(7) = 1
    → max(1,1)+1 = 2
  → max(1,2)+1 = 3 ✅
```
